# unity.hex — Open‑Source Modular Utility Drone Platform

unity.hex is an open‑source hardware project focused on creating modular, repairable,
and highly customizable utility‑class multirotors. The platform includes the Mk1, Mk2,
and Mk3 airframes, designed for affordability, field‑serviceability, and community‑driven
improvements.

This repository contains:
- CAD files (frames, mounts, accessories)
- STL/STEP exports
- Wiring diagrams
- Bill of materials (BOM)
- Flight controller configurations
- Assembly documentation

---

## ✨ Project Goals

- Create a fully open‑source drone platform that anyone can build, modify, and improve.
- Ensure all forks remain open‑source unless explicit permission is granted.
- Require attribution and modification disclosure for all derivative works.
- Support both hobbyist and commercial use while protecting the original author’s credit.
- Encourage community collaboration and transparent hardware development.

---

## 🔧 Hardware Overview

### Mk1 — Entry Utility Frame
Lightweight, low‑cost, beginner‑friendly platform for general utility tasks.

### Mk2 — DIY Expansion Frame
Designed for modders, experimenters, and custom payload development.

### Mk3 — Flagship Utility Frame
High‑strength, modular, and optimized for real‑world use cases such as mapping,
inspection, and payload delivery.
